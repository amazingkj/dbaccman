# DBAccMan 기능 요약서

## 개요

| 항목 | 내용 |
|------|------|
| 시스템명 | DBAccMan (Database Account Manager) |
| 목적 | 다중 데이터베이스 계정 통합 관리 |
| 지원 DB | MySQL, PostgreSQL, Oracle |
| 기술 스택 | Kotlin/Ktor (Backend), React/TypeScript (Frontend) |

---

## 주요 기능

### 1. 계정 관리
| 기능 | 설명 |
|------|------|
| 계정 생성 | 사용자 계정 생성 및 비밀번호 정책 설정 |
| 계정 삭제 | 사용자 계정 삭제 |
| 비밀번호 변경 | 비밀번호 변경 및 만료 정책 관리 |
| 계정 잠금 해제 | 잠긴 계정 해제 |
| 만료 예정 알림 | 비밀번호 만료 예정 계정 목록 조회 |

### 2. 권한 관리
| 기능 | 설명 |
|------|------|
| 권한 조회 | 사용자별 데이터베이스/테이블 권한 조회 |
| 권한 부여 | SELECT, INSERT, UPDATE, DELETE 등 권한 부여 |
| 권한 회수 | 기존 부여된 권한 회수 |

### 3. 세션 관리
| 기능 | 설명 |
|------|------|
| 세션 모니터링 | 활성 세션 실시간 조회 |
| 세션 종료 | 특정 세션 강제 종료 |
| 쿼리 종료 | 실행 중인 쿼리만 종료 |

### 4. Tablespace 관리
| 기능 | 설명 |
|------|------|
| Tablespace 조회 | 용량, 사용량, 상태 조회 |
| Tablespace 생성 | 신규 Tablespace 생성 |
| Tablespace 삭제 | 기존 Tablespace 삭제 |
| 테이블 이동 | 테이블을 다른 Tablespace로 이동 |

### 5. 테이블/인덱스 관리
| 기능 | 설명 |
|------|------|
| 데이터베이스 목록 | 전체 데이터베이스 조회 |
| 테이블 목록 | 테이블 정보 및 용량 조회 |
| 인덱스 조회 | 테이블별 인덱스 조회 |
| 인덱스 생성/삭제 | 인덱스 관리 |

### 6. SQL Console
| 기능 | 설명 |
|------|------|
| 쿼리 실행 | SQL 쿼리 직접 실행 |
| 결과 조회 | 쿼리 결과 테이블 형식 표시 |
| 위험 쿼리 차단 | DROP, TRUNCATE 등 위험 쿼리 경고 |

### 7. 감사 로그
| 기능 | 설명 |
|------|------|
| 작업 이력 조회 | 모든 관리 작업 로그 기록 |
| 필터링 | 사용자, 작업 유형별 필터 |

---

## 보안 기능

- JWT 기반 인증
- 시스템 계정 수정 차단 (Oracle: SYS, SYSTEM 등)
- 위험 SQL 실행 경고
- 세션 타임아웃
