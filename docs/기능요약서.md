# DBAccMan Feature Summary

## Overview

| Item | Description |
|------|-------------|
| System Name | DBAccMan (Database Account Manager) |
| Purpose | Unified multi-database account management |
| Supported DB | MySQL, PostgreSQL, Oracle |
| Tech Stack | Kotlin/Ktor (Backend), React/TypeScript (Frontend) |

---

## User Roles

| Role | Description |
|------|-------------|
| Admin | Full access to all management features |
| User | Access to own schema data only (My Tables, My Tablespaces, My Console) |

---

## Admin Features

### 1. Account Management
| Feature | Description |
|---------|-------------|
| Create Account | Create user accounts with password policy |
| Delete Account | Remove user accounts |
| Change Password | Password change and expiration policy |
| Unlock Account | Unlock locked accounts |
| Expiration Alerts | View accounts with expiring passwords |

### 2. Permission Management
| Feature | Description |
|---------|-------------|
| View Permissions | Query user permissions by database/table |
| Grant Permissions | Grant SELECT, INSERT, UPDATE, DELETE, etc. |
| Revoke Permissions | Revoke existing permissions |
| Set Tablespace (Oracle) | Set default tablespace for user |

### 3. Session Management
| Feature | Description |
|---------|-------------|
| Session Monitoring | Real-time active session view |
| Kill Session | Force terminate specific sessions |
| Kill Query | Terminate running queries only |

### 4. Tablespace Management
| Feature | Description |
|---------|-------------|
| View Tablespaces | Check capacity, usage, status |
| Create Tablespace | Create new tablespace |
| Delete Tablespace | Remove existing tablespace |
| Move Table | Move tables between tablespaces |

### 5. Table/Index Management
| Feature | Description |
|---------|-------------|
| Database List | View all databases/schemas |
| Table List | View table info and size |
| Index Query | View indexes per table |
| Create/Delete Index | Index management |

### 6. SQL Console
| Feature | Description |
|---------|-------------|
| Execute Query | Run SQL queries directly |
| View Results | Display results in table format |
| Dangerous Query Warning | Warning for DROP, TRUNCATE, etc. |

---

## User Features (Non-Admin)

### 1. My Tables
| Feature | Description |
|---------|-------------|
| View Tables | Tables owned by or accessible to user |
| View Columns | Column structure of tables |
| View Indexes | Index information |
| View Data | Preview table data (limited rows) |

### 2. My Tablespaces
| Feature | Description |
|---------|-------------|
| View Quotas | Tablespace quotas assigned to user |
| Default/Temp Tablespace | View assigned tablespaces |
| View Tables in Tablespace | Click tablespace to see tables |

### 3. My Console
| Feature | Description |
|---------|-------------|
| Execute Query | Run queries within own schema |
| Schema Selection | Select target schema for query |

---

## Dashboard

| Feature | Description |
|---------|-------------|
| Health Status | Overall system health indicator |
| Quick Stats | Account, session, table, tablespace counts |
| Expiring Accounts | Accounts with passwords expiring soon |
| Locked Accounts | Currently locked accounts |
| Long Running Queries | Queries running over threshold |
| Critical Tablespaces | Tablespaces over 90% usage |

---

## Security Features

- JWT-based authentication
- System account protection (Oracle: SYS, SYSTEM, etc.)
- Dangerous SQL execution warning
- Session timeout
- Role-based access control (Admin/User)
- Audit logging for all operations

---

## Database-Specific Features

### Oracle
- Tablespace quota management
- User default tablespace setting
- PDB/CDB support
- System privilege management

### MySQL
- Global privilege management
- Database-level permissions
- InnoDB tablespace support

### PostgreSQL
- Schema-based permissions
- Schema privilege check (USAGE, CREATE)
- Role management
